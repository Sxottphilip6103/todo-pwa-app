# Todo PWA

A Progressive Web App to-do list with offline support, installable, and fast loading.

## Features

✅ **Add, complete, and delete tasks**
✅ **Filter tasks** (All, Active, Completed)
✅ **Local storage** - Tasks persist between sessions
✅ **Offline support** - Works without internet
✅ **Installable** - Add to home screen on mobile
✅ **Fast loading** - Service worker caching
✅ **Responsive design** - Works on all devices

## Live Demo

https://Sxottphilip6103.github.io/todo-pwa-app/

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start adding tasks!

## Installation

On supported browsers (Chrome, Firefox, Edge), look for the "Install App" button to add the app to your home screen.

## PWA Features

- **Service Worker** - Offline caching
- **Manifest.json** - App metadata and icons
- **Responsive** - Mobile-first design
- **HTTPS** - GitHub Pages enables HTTPS

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Service Workers
- Local Storage API
